# منصة تقييم الفجوة في المهارات (Skill Gap Assessment)

منصة متكاملة لتقييم المهارات الشخصية والتواصلية. الواجهة الخلفية مبنية باستخدام FastAPI، وتستخدم قواعد بيانات MongoDB لحفظ الإجابات والتقارير. تعتمد المنصة على نموذج ذكاء اصطناعي (LLM) لتحليل النتائج وإصدار تقرير باللغة العربية يوضح نقاط القوة والفجوات.

## 🌟 المميزات الأساسية
* **التقييم الذكي:** توليد تقرير فجوات مخصص باستخدام الذكاء الاصطناعي بناءً على درجات الكفاءة.
* **الكفاءات المدروسة:** يقيس الاستماع الفعّال، وضوح التعبير، تقديم وتقبّل الملاحظات، إدارة الخلافات، والتواصل الكتابي.
* **آلية التقييم:** تعتبر الكفاءة "نقطة قوة" إذا كانت درجتها 4.0 أو أعلى، وما دون ذلك يعتبر "فجوة" تحتاج إلى تطوير.
* **الأمان والحماية:** تطبيق تقييد الطلبات (Rate Limiting) بمعدل 10 طلبات في الدقيقة لعمليات الإرسال لمنع الإساءة.

## 🛠️ التقنيات المستخدمة
* **إطار العمل:** FastAPI للواجهة الخلفية.
* **قاعدة البيانات:** MongoDB (عبر مكتبة Motor للعمليات غير المتزامنة).
* **الذكاء الاصطناعي:** AsyncOpenAI للتكامل مع النماذج اللغوية.
* **التحقق من البيانات:** Pydantic.
