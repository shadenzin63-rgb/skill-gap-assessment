# منصة تقييم الفجوة في المهارات (Skill Gap Assessment)

منصة متكاملة لتقييم المهارات الشخصية والتواصلية. الواجهة الخلفية مبنية باستخدام FastAPI[cite: 3]، وتستخدم قواعد بيانات MongoDB لحفظ الإجابات والتقارير[cite: 3]. تعتمد المنصة على نموذج ذكاء اصطناعي (LLM) لتحليل النتائج وإصدار تقرير باللغة العربية يوضح نقاط القوة والفجوات[cite: 2].

## 🌟 المميزات الأساسية
* **التقييم الذكي:** توليد تقرير فجوات مخصص باستخدام الذكاء الاصطناعي بناءً على درجات الكفاءة[cite: 2].
* **الكفاءات المدروسة:** يقيس الاستماع الفعّال، وضوح التعبير، تقديم وتقبّل الملاحظات، إدارة الخلافات، والتواصل الكتابي[cite: 5].
* **آلية التقييم:** تعتبر الكفاءة "نقطة قوة" إذا كانت درجتها 4.0 أو أعلى، وما دون ذلك يعتبر "فجوة" تحتاج إلى تطوير[cite: 6].
* **الأمان والحماية:** تطبيق تقييد الطلبات (Rate Limiting) بمعدل 10 طلبات في الدقيقة لعمليات الإرسال لمنع الإساءة[cite: 3].

## 🛠️ التقنيات المستخدمة
* **إطار العمل:** FastAPI للواجهة الخلفية[cite: 3].
* **قاعدة البيانات:** MongoDB (عبر مكتبة Motor للعمليات غير المتزامنة)[cite: 3].
* **الذكاء الاصطناعي:** AsyncOpenAI للتكامل مع النماذج اللغوية[cite: 2].
* **التحقق من البيانات:** Pydantic[cite: 4].
